# v0.2.1 Release Notes

Release date: 2026-05-03

## Highlights

- Added package metadata needed for a polished PyPI project page.
- Added a tag-driven GitHub Actions publish workflow for Trusted Publishing to PyPI.
- Documented the repeatable release flow for PyPI publication and Homebrew follow-up updates.

## Included Changes

- Added `Homepage`, `Repository`, and `Documentation` project URLs in `pyproject.toml`.
- Added package keywords and PyPI classifiers in `pyproject.toml`.
- Added `.github/workflows/publish.yml` to build artifacts and publish them on `vX.Y.Z` tags.
- Added `docs/release/packaging.md` for release preparation, publishing, and Homebrew update steps.
- Updated the README to reference the release packaging documentation.

## Upgrade Notes

- No CLI behavior changes are included in this release.
- Future PyPI releases should be published by pushing a version tag such as `v0.2.1` after the release commit is on GitHub.

## Verification

- `uv build`
- `uvx twine check dist/*`
- `uv run pytest`
