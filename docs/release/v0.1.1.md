# v0.1.1 Release Notes

Release date: 2026-05-03

## Highlights

- Added Gmail search support with raw query input, saved queries, query examples, and a search cheat sheet.
- Added message inspection and structured output with `read`, JSON output, and CSV output for list-style commands.
- Improved label workflows with default `list` actions, action discovery, exact label-name support, and label mutation actions.
- Added CLI usability improvements including config discovery, short option aliases, `--version`, and `--verbose`.
- Added auth diagnostics, opt-in live Gmail integration tests, Docker packaging, pre-commit hooks, and CI.

## Included Changes

- Added `gmail-tool labels`, `gmail-tool label`, `gmail-tool search`, `gmail-tool read`, and `gmail-tool auth-check`.
- Added OAuth desktop and service account authentication modes.
- Added global filters for date ranges and starred state.
- Added `--format json|csv` for label and search list outputs.
- Added label actions `count`, `list`, `label-add:<name>`, and `label-remove:<name>`.
- Added exact label-name resolution for `gmail-tool label <LABEL>`, while still accepting exact label IDs.
- Added config discovery priority across CLI commands.
- Added live Gmail integration tests, Dockerfile, pre-commit config, and GitHub Actions CI.

## Upgrade Notes

- `gmail-tool label <LABEL>` now accepts an exact label name such as `@Later` in addition to exact label IDs such as `Label_66`.
- `gmail-tool label` and `gmail-tool search` default to the `list` action.
- Use `--action` or `-a` to switch actions and `--format` or `-f` for structured list output.

## Verification

- Focused application and CLI tests passed before release preparation.
- Ruff checks passed for the touched application and CLI files.
