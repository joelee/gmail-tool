# v0.3.1 Release Notes

Release date: 2026-05-05

## Highlights

- Added a first-class `delete` action for both `gmail-tool search` and `gmail-tool label`.
- Fixed Homebrew formula generation so native Python dependencies install from wheels instead of failing through source-build paths.

## Included Changes

- Added `--action delete` for `search` and `label` to move all matching messages to Gmail Bin.
- Added confirmation-by-default and `--force` support for the new batch delete action.
- Added single-line progress output for batch delete operations, aligned with existing long-running mutation actions.
- Updated action discovery and help output so `delete` appears in `--list-actions` and `--help-action delete`.
- Fixed Homebrew formula generation to prefer wheel resources over sdists, avoiding install failures for native dependencies such as `cryptography` and `cffi`.

## Upgrade Notes

- Batch delete operations now require the `https://www.googleapis.com/auth/gmail.modify` scope, matching other mutating Gmail actions.
- If a tap formula was generated from older packaging logic, regenerate it so native dependencies use wheels instead of sdists.

## Verification

- `uv run pytest`
- Regenerated `../homebrew-oss/Formula/gmail-tool.rb` and verified it now references wheel resources for native dependencies.
