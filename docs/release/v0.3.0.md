# v0.3.0 Release Notes

Release date: 2026-05-04

## Highlights

- Added a new `message` command group and moved full-message reading from `gmail-tool read` to `gmail-tool message read`.
- Added `gmail-tool message delete` with confirmation and `--force` support.
- Improved long-running batch workflows with progress output, backup delete support, action help, and a clearer label mutation interface.

## Included Changes

- Improved `README.md` onboarding with clearer product positioning, pip and Homebrew installation guidance, and a simpler quick-start flow.
- Added command descriptions to CLI help output and sorted help options and commands alphabetically.
- Removed the legacy `auth-check` alias in favor of `gmail-tool auth check`.
- Added `backup --delete` with confirmation and `--force`, moving successfully written messages to Gmail Bin after backup.
- Added help text for `search` and `label` arguments and options.
- Added `--help-action <action_name>` for `search` and `label` to print action-specific help and supported sub-options.
- Changed label mutation actions to use `--action label-add --name <label_name>` and `--action label-remove --name <label_name>`.
- Refactored `gmail-tool read <message-id>` to `gmail-tool message read <message-id>`.
- Added `gmail-tool message delete <message-id>` with confirmation and `--force`.
- Updated user-facing documentation examples to use `gmail-tool` instead of `uv run gmail-tool`.
- Added single-line progress output for long-running batch actions such as `backup`, `label-add`, and `label-remove`, while keeping `count` and `list` quiet.

## Upgrade Notes

- Breaking change: replace `gmail-tool read <message-id>` with `gmail-tool message read <message-id>` in scripts, aliases, and documentation.
- Mutating Gmail actions such as `label-add`, `label-remove`, `message delete`, and backup delete flows require the `https://www.googleapis.com/auth/gmail.modify` scope instead of read-only OAuth access.
