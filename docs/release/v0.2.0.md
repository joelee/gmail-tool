# v0.2.0 Release Notes

Release date: 2026-05-03

## Highlights

- Added a resumable `backup` action that writes real `.eml` files from Gmail raw message content.
- Added config-backed and CLI override backup paths, with resume-safe skipping of already backed-up messages.
- Improved action discovery by sharing `--list-actions` across `label` and `search` with aligned descriptions.
- Refined CLI action behavior with stable error reporting and renamed label mutation actions.

## Included Changes

- Added `backup` for both `gmail-tool label` and `gmail-tool search`.
- Added `[backup].path` configuration support in `config.toml`.
- Added `--backup-path <DIR>` for the `backup` action.
- Added resumable backup behavior by skipping message IDs that already exist on disk.
- Added single-line backup progress output with date, message ID, sender email, and decoded subject text.
- Added shared `--list-actions` support for both `label` and `search`.
- Added one-line action descriptions and aligned action-list output.
- Renamed label mutation actions to `label-add:<name>` and `label-remove:<name>`.
- Fixed CLI non-list `--format` validation so the error output is consistent across environments.

## Upgrade Notes

- Use `backup` with `--action`, for example `gmail-tool search -a backup ...` or `gmail-tool label <LABEL> -a backup`.
- Override the configured backup destination with `--backup-path <DIR>` when needed.
- Label mutation actions are now named `label-add:<name>` and `label-remove:<name>`.

## Verification

- Full test suite passed during release preparation.
- Ruff checks passed across `src/gmail_tool` and `tests`.
