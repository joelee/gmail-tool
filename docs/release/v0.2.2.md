# v0.2.2 Release Notes

Release date: 2026-05-03

## Highlights

- Improved first-run authentication so normal OAuth users no longer need a `config.toml` file.
- Added dedicated `auth` helper commands for login, verification, token cleanup, and resolved auth paths.
- Improved project quality reporting with coverage artifacts, coverage badges, and broader unit test coverage.

## Included Changes

- Added configless OAuth defaults with XDG-based client secret and token paths.
- Added `gmail-tool auth login`, `gmail-tool auth check`, `gmail-tool auth paths`, and `gmail-tool auth logout`.
- Added `gmail-tool auth login --no-browser` for headless OAuth flows.
- Improved auth error output with guided setup instructions.
- Tightened local OAuth client secret and token file permissions.
- Added Homebrew packaging documentation and a formula refresh helper script.
- Added CI coverage JSON/XML artifacts, a generated coverage badge, and a workflow to refresh the checked-in coverage badge on `main`.
- Added README badges for release, CI, coverage, Python support, downloads, and license.
- Added focused unit tests for Gmail gateway request/response handling and OAuth credential flows.

## Upgrade Notes

- OAuth desktop users can now start with `gmail-tool auth login` without creating a local `config.toml` first.
- The default OAuth file locations are now under XDG config and state directories.
- Use `gmail-tool auth check` for authentication diagnostics.

- `uv run pytest --cov=src/gmail_tool --cov-report=term-missing --cov-report=xml --cov-report=json`
