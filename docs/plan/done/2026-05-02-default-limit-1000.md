# Default Limit 1000 Plan

## Goals

- Change the default label action limit to `1000` when `--limit` is not provided.
- Keep the behavior config-driven through `config.toml`.
- Update tests and docs so the default is explicit.

## Design Plan

1. Update the default limit value in `config.toml`.
2. Update tests that construct settings directly so they reflect the new default.
3. Document the default in usage and configuration docs.

## TDD Strategy

- Update the application-level test that exercises default list behavior first.
- Apply the minimal config and fixture changes needed to satisfy the tests.

## Integration Test Coverage Plan

- Existing integration tests cover the default limit path through the application layer.

## Risks

- The change should only affect calls where `--limit` is omitted.
