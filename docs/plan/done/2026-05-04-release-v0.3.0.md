# Release v0.3.0

## Goal

Prepare a `v0.3.0` release for the recent CLI and UX changes, including the breaking command rename from `gmail-tool read` to `gmail-tool message read`.

## Scope

- Bump the package version to `0.3.0`.
- Roll current `CHANGELOG.md` `Unreleased` entries into a new `v0.3.0` section.
- Add release notes in `docs/release/v0.3.0.md`.
- Verify the release prep with targeted tests.

## Verification

- Run focused unit and integration tests for the recently changed CLI paths.
